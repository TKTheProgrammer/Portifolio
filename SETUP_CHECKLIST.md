# Portfolio Setup Checklist

Use this checklist to get your portfolio live on GitHub Pages quickly!

## ☐ Before You Start

- [ ] Have a GitHub account (create one at github.com if needed)
- [ ] Know your GitHub username
- [ ] Have your contact information ready (email, LinkedIn, etc.)

## ☐ Step 1: Create Repository

1. [ ] Go to github.com and log in
2. [ ] Click the "+" icon → "New repository"
3. [ ] Name it EXACTLY: `tktheprogrammer.github.io` (or use your exact GitHub username)
4. [ ] Make it **Public**
5. [ ] Click "Create repository"

## ☐ Step 2: Upload Files

1. [ ] On the repository page, click "uploading an existing file"
2. [ ] Upload `index.html`
3. [ ] Upload `README.md` (optional but recommended)
4. [ ] Write commit message: "Initial portfolio commit"
5. [ ] Click "Commit changes"

## ☐ Step 3: Enable GitHub Pages

1. [ ] Go to repository **Settings** (tab at the top)
2. [ ] Click **Pages** in the left sidebar
3. [ ] Under "Source", select **Deploy from a branch**
4. [ ] Choose **main** branch
5. [ ] Choose **/ (root)** folder
6. [ ] Click **Save**
7. [ ] Wait 2-5 minutes for deployment

## ☐ Step 4: Verify It's Live

1. [ ] Visit `https://tktheprogrammer.github.io`
2. [ ] Check all sections load correctly
3. [ ] Test on mobile device or use browser dev tools

## 🎯 Quick Tips

1. **Test Before Committing**: Open `index.html` in your browser locally first
2. **Backup Your Work**: Keep a local copy of your portfolio
3. **Use Branches**: For major changes, create a branch and test before merging
4. **Mobile First**: Always check how it looks on mobile
5. **Keep It Updated**: An outdated portfolio is worse than no portfolio

## 🆘 Common Issues

**Site not loading?**
- Check repository name is exactly `yourusername.github.io`
- Verify Pages is enabled in Settings
- Wait 5-10 minutes after enabling Pages

**Changes not showing?**
- Hard refresh browser (Ctrl+Shift+R or Cmd+Shift+R)
- Clear browser cache
- Wait 1-2 minutes for GitHub to rebuild

**Broken layout?**
- Make sure you didn't accidentally delete closing tags
- Check that you saved the file
- Validate HTML at validator.w3.org
